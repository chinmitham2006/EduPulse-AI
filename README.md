# EduPulse AI — Student Performance Analyst

EduPulse AI is an AI-powered student performance analysis application that analyzes students' marks and attendance, visualizes academic performance, and provides insights and recommendations to help students identify weaknesses and improve their academic outcomes.

## 🚀 Live Demo

[**Try EduPulse AI here**](https://afeb7443e92b7e694c.gradio.live)

## ✨ Features

- 📊 Student marks and attendance analysis
- 📈 Academic performance visualizations
- 🔍 Identification of areas for improvement
- 💡 AI-powered insights and recommendations
- 🖥️ Interactive user interface built with Gradio

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Gradio
- AI models

## ⚙️ How It Works

1. Processes student marks and attendance data.
2. Analyzes academic performance.
3. Visualizes results through charts and graphs.
4. Provides insights to help identify areas for improvement.

## 🎯 Objective

To help students better understand their academic performance through data analysis, visualization, and AI-powered insights.

## 🔮 Future Improvements

- Integration with the Groq API for enhanced AI-generated insights
- More detailed performance predictions
- Personalized study recommendations
- Support for larger student datasets
